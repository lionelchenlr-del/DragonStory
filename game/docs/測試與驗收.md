# v7 測試與驗收

完整數值見根目錄 VALIDATION.json。[美術重作及人工檢視](v7美術與驗收.md) 列出模型與路徑。

## 已執行

- Luau 程式編譯；經濟、掉寶、存檔、Lv.800 與飛行的純規則檢查。
- 實際 TravelService 配合引擎替身的 155 項檢查，保留反向轉彎修正。
- Studio 重開二進位場景，檢查 62 個 v7 外觀、37 個環境模板、18 種葉冠和 6,004 片主要葉片。
- 確認七島實際 266 棵樹、沒有舊的 FacetedCanopy 球狀樹冠；模型根點、比例與葉片稜線正確。
- Studio 單人客戶端與伺服器：升降、加速、反轉、懸停、落地、下龍恢復、六個分頁、126 個怪物、購買、裝備、拒絕未持有裝備與擊殺獎勵。
- 桌面實際開啟 v7，觀察葉片、草花、岩壁與玩家胸甲，並以鍵盤騎龍、上升與移動。檢視的遊戲畫面與離線資料渲染分開記錄。

幾何索引佔純測試斷言的大部分，不能視為同等數量的獨立遊戲情境。這些測試也不能代替多人、低階手機和真實延遲環境的驗收。

## 重跑

安裝官方 Luau CLI 後執行 `python3 tests/run_checks.py`。

以官方 Studio CLI 的 RunScript，在測試副本執行 `tests/engine/RunIntegration.luau`。觀察 V7_ART_REGRESSION 與 V6_SERVER_REPORT；後者沿用測試訊息名稱，Ok 應為 true。測試會暫時插入腳本與 Remote，不應另存回正式檔案。

官方 CLI 文件：https://create.roblox.com/docs/studio/cli
