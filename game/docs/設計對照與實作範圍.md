# 設計稿與 v7 實作範圍

[原稿與目前模型對照](../專案預覽.html)。原始設計圖在 art/originals，17 張 PNG 的雜湊保持一致。

本版將球形樹冠換成分叉枝幹與尖葉，將圓鼓地形換成有切面的岩壁，並重作草花、屋頂、棚架、礦洞木構、NPC、角色甲片、鱗甲、毛束與羽片。遊戲內確實放置了這些模型。

新預覽 PNG 是相同造型配方的另行渲染，不是 Studio 截圖；不能用另一套燈光的圖片宣稱遊戲內已逐像素還原設計。

仍有差距的部分包括插畫式手繪紋理、進階毛髮與肌肉雕刻、裝備上的微小花紋，以及逐處精確的地形輪廓。玩家仍保留個人 Roblox 頭部與原生動作。

全部原始地圖保留於離線對照頁；遊戲內使用高清導引，減少完整大圖的重複打包。怪物與裝備圖鑑的原圖仍內嵌。


最新版涵蓋、分散規則與驗收請見 [v8怪物分布與驗收](v8怪物分布與驗收.md)。
