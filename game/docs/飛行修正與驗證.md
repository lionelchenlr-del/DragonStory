# v6.1 飛行閃爍修正

2026-11-14 更新；專案入口仍為 DragonAwakening-Polished-v6.rbxl，原有連結可繼續使用。

## 原因與修正

原本伺服器移動鎖定的角色根部，鏡頭直接跟隨分段收到的位置；龍則自行做另一套平滑，且用原始每幀位置差求俯仰。這會讓鏡頭、騎乘角色和龍在不同幀顯示不同的位置，俯仰也隨封包間隔反覆跳動。180 度反轉時，方向向量插值會接近零，隨後突然翻轉。

新增 RideMotion 以臨界阻尼平滑位置，並平滑速度、角度與傾斜。RidePresentation 在鏡頭更新之前產生共同姿態，以不參與物理、沒有可執行腳本的角色外觀副本顯示騎手，鏡頭跟隨同一個平滑錨點。CompanionRenderer 與 WorldRenderer 依序使用相同位置繪製龍和裝備。真正的角色不被客戶端平滑器改寫；飛行方向仍送至 TravelService，由伺服器驗證和計算。反轉改用最短角度插值。

顯示層約落後伺服器 0.1 秒，避免分段更新造成跳動；超過 80 格的位移視為重置，直接同步，避免復活或傳送時鏡頭穿越整張地圖。

## 已執行

- 純規則及經濟／掉寶／存檔測試通過；實際 TravelService 配合引擎替身的 155 項檢查通過，包含反轉方向不歸零及不突然翻轉。
- Studio 真正的 Vector3／CFrame 測試：30、60、120 幀率，模擬 12–25 次／秒的不規則位置更新、停止懸停和傳送。60 幀率俯仰最大單幀變化由舊算法的 0.18 rad 降為 0.01728 rad。這是特定測試資料的結果，不代表所有網路情境。
- Studio 單人客戶端＋伺服器：上升、下降、加速向前、反轉、懸停、落地、下龍；逐幀檢查同一個騎手位置、龍位置與鏡頭目標，並驗證下龍後隱藏外觀、鏡頭、縮放和顯示副本全部恢復。
- 購買、持有驗證、裝備、擊殺與獎勵回歸通過。

- 桌面鍵盤試飛：F 騎乘、W 平飛、空白鍵上升至 111 格、Shift＋W 加速、S 反轉、Q 下降、F 下龍後再騎乘，確認畫面可正常顯示。完成後停止測試並保留專案開啟。

完整數值見 VALIDATION.json 的 flightFlickerFix。

## 相關放置路徑

- ReplicatedStorage/DragonShared/RideMotion：平滑計算。
- ReplicatedStorage/DragonShared/UI/RidePresentation：本機騎手顯示及鏡頭；不更動權威角色。
- ReplicatedStorage/DragonShared/UI/CompanionRenderer：龍的顯示及平滑傾斜。
- ReplicatedStorage/DragonShared/UI/WorldRenderer：裝備使用相同的騎手位置。
- ServerScriptService/DragonServer/TravelRules 與 TravelService：伺服器轉向。

## 重測

1. 在 Studio 開啟更新後的 rbxl，若舊測試仍在執行，先停止並重新開啟檔案，再按 Play。
2. 按 F 騎龍；按住 W 與空白鍵，上升數秒。放開後確認能穩定懸停。
3. 按住 W＋Shift，加速後切換 S、A、D，確認鏡頭和騎手不會來回錯位。
4. 按住 Q 下降，在地面附近按 F 下龍；角色可正常走路、顯示、縮放和開啟商店。
5. 死亡或重開測試後重複騎乘；應只有一隻騎乘龍與一個騎手外觀。

可透過官方 Studio CLI 的 RunScript 在測試副本執行 tests/engine/RunIntegration.luau。該腳本暫時插入測試來源，不要另存回正式專案。官方說明：https://create.roblox.com/docs/studio/cli

多人、低階手機及人工實際網路不穩情境仍需在目標裝置驗收。
