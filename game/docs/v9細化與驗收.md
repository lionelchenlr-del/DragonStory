# v9 全怪物與裝備再次細化

28 種怪物、30 件裝備均更新為 AuthoredRevision=9。四階騎乘龍沿用原本外觀，本次對象是全部怪物及裝備。七島環境與 v8 怪物分布也保留。

## 查看更新

專案預覽頁提供全部 58 件模型及 v8／v9 切換比較。預覽使用相同造型資料另行渲染；Studio 的光照、陰影、布林接縫和材質效果可能有差異，並非實機截圖。手繪貼圖與逐項高精度雕刻尚未完全還原原稿。

獸型怪的頭部原先遮住部分眼睛，已修正眼睛深度；更新眉骨、鼻孔、口緣、耳內層、毛流與曲線角。獅鷲的犬型口鼻改成鉤喙。翅膀羽軸、羽枝保留在 WingLeft／WingRight 群組，繼續跟著翅膀運動。

裝備減少原先大塊的菱形胸甲，採胸板、腹部疊片與薄飾邊。頭盔、胸甲、靴子的主題徽記不同；胸甲背面也有雕飾，平常第三人稱視角可見。寶石減少大片自發光，改用玻璃色面、小高光與金屬鑲座。

## 驗證範圍

詳細執行結果記錄在根目錄 VALIDATION.json。

1. 實際重開烘焙後的二進位專案，建立全部 58 件外觀，檢查版本、可見零件數、外觀不參與實體碰撞。
2. 驗證 14 個左右靴群組的分離與鞋底對齊，史萊姆半透明層仍保存。
3. 重測 126 個實際地面位置、分散間距、巡邏與兩隻一般怪追擊限制。
4. 重測實際購買扣款、未持有裝備拒絕、裝備套用、擊殺獎勵、上升下降、騎乘鏡頭同步及地圖生成點。
5. 純 Luau 驗證經濟、掉落、存檔、升級與幾何資料；檢查全部 Luau 可編譯，原有規則模組、分布資料與設計圖雜湊一致。

本次驗收為本機單人及固定情境，多人延遲與手機效能仍需另行測試；不把元件數增加當作畫面品質的唯一證明。

圖鑑、背包與商店的詳細外觀預設顯示真正的立體模型，可切換設計圖並用左右按鈕旋轉；切換或關閉會釋放舊的預覽。
