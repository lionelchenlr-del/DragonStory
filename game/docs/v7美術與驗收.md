## 改動邊界

沿用七島的地點座標、跨島間隙與 Lv.800 進度；沒有改動怪物的掉落率、商品價格或裝備能力。交易、裝備持有檢查、傷害與獎勵仍由伺服器控制。

原始設計圖保留，離線對照頁能直接打開。遊戲內地圖使用高清導引，避免把八張完整地圖像素重複塞進專案；裝備／怪物圖鑑仍可顯示原設計。

目前是更細緻的風格化 3D。手繪表面紋理、進階毛髮及逐件高精度雕刻仍未完整還原；角色的 Roblox 個人頭部與原生動作維持。

## 驗證

詳細實測數值記錄於根目錄 VALIDATION.json；同時保留正式 Studio 客戶端／伺服器測試與美術回歸腳本於 tests/engine。

- 重開二進位專案，檢查 62 個 v7 外觀、37 個環境模板、18 個葉冠類型與 6,004 片主要葉片。
- 實際地圖檢查 266 棵樹，確定沒有舊的 FacetedCanopy 球狀樹冠。
- 檢查葉片稜線、色層、可縮放模板、地面與七座島。
- 在 Studio 單人模式重測升降、加速、反向轉彎、懸停、下龍，以及角色／龍／鏡頭的逐幀同步。
- 重測購買扣款、裝備、拒絕未持有裝備、擊殺與獎勵。
- 以 Luau 規則測試檢查經濟、掉寶、存檔、等級門檻及飛行服務；幾何索引檢查佔大部分數量，不能視作同等數量的獨立遊戲情境。

多人同步、真實網路延遲和低階手機幀率，仍需在目標裝置檢驗。草叢按少量固定葉色合併，減少大量獨立葉片的物件成本。

## 人工檢視步驟

1. 開啟主專案按 Play，從降落場看周圍的新綠葉、金葉與針葉樹；靠近後應看到葉片邊緣和分叉枝幹。
2. 前往村莊，確認屋頂是中央高、屋簷低，看到瓦片、窗框和條紋棚架；商人與委託角色有衣襟、腰帶及職業配件。
3. 騎龍升高，看岩壁切面、平台層次與懸石；跨島仍需要飛行。
4. 查看怪物、裝備和龍的預覽；穿戴胸甲後應可看見外殼與肩甲。
5. 降落、下龍、購買和擊殺，確認本次外觀更新沒有影響原有玩法。
