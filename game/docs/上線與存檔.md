# 上線與存檔

## 本地測試

預設 Settings.StudioPersistence=false，按 Stop 後測試進度不保留，讓你能重跑新手流程。這不會關閉正式伺服器存檔；ProfileStore 會依是否 Studio 選擇資料來源。

StudioPersistence=true 時使用獨立的 `DragonAwakening_TEST_v5`，正式伺服器使用 `DragonAwakening_v1`。需要發布到自己的測試體驗，並開啟適當的 Studio API 存取後才能驗證 DataStore；本地檔案不會自動替你發布或更改帳號設定。

資料格式 v2 接受 v1／v2，重新檢查金幣、等級、背包、裝備、圖鑑與擊殺。既有且仍在 Catalog 的物品保留；未知物品不會被載入。新增待領、委託、祕境與復活點紀錄。等級上限改為 800。

同一正式資料庫若仍有舊版伺服器，舊程式可能不理解 v2；更新既有正式體驗時應先備份資料、在測試體驗驗證，再安排舊伺服器退出。若這是全新的遊戲，可將 DataStoreName 改成專屬名稱。

存檔採 UpdateAsync、180 秒租約、45 秒保存週期。無法取得有效資料時不會把新手資料覆蓋舊資料；失去租約會停止交易並要求玩家重連。

## 原圖與曲面模型

v6 的 62 個外觀與七島崖壁已在 Studio 烘焙為實體曲面並存入 BakedArt.rbxmx。一般遊戲直接複製它們，不需要帳號啟用 EditableMesh。原圖仍用 EditableImage 顯示，無法使用時顯示 3D 模型或原生標記圖。

v7 主專案約 76 MB。完整原始地圖保留於離線檔案，遊戲內用高清標記圖；角色／裝備與環境模型均已包含。正式發布前仍應在測試體驗確認存檔、多人與目標裝置效能。

圖片鍵為 kit_1…kit_7、emperor、evolution、map_world 與七個 map_島嶼ID。建議先在獨立測試體驗驗證。Roblox 檔案格式及大小說明：https://create.roblox.com/docs/projects/place-files

BakedArt.rbxmx 是主要模型來源；本版沒有另外提供更新過的通用 GLB，以免與舊版造型混淆。原始 Luau 配方與烘焙曲面均保留。

## 效能設定

七島場景啟用 StreamingEnabled，半徑 128／1024；怪物外觀只建立 650 格內最近 22 隻，裝備外觀限制 350 格，龍限制 1000 格。伺服器仍維持全部 126 個生命狀態。手機上線前應實際量測大型模型、原圖記憶體、多人與飛行載入的幀率。

Prototype 的戰鬥數值、金幣價格、XP 速度與飛行速度可在 Catalog／Settings／TravelService 調整；掉落機率修改時必須同步 Settings 與 LootInfo，啟動驗證會拒絕兩者不一致。
