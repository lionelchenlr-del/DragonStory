# 龍之覺醒：天空群島 v9

在 Roblox Studio 開啟 **DragonAwakening-Atelier-v9.rbxl**，按 Play。

[查看全部怪物與裝備，切換 v8／v9 對照](專案預覽.html)。28 種怪物及 30 件裝備全部再次更新。圖片以相同造型資料另行渲染，不是 Studio 截圖。

## 本次細化

- 臉部：獸型怪原先部分眼睛埋在頭部內，已調整眼窩、虹膜與眉骨；增加口鼻接縫、鼻孔、耳內層及眼睛反光。
- 獸型：大型毛塊改為方向明確的細毛束，角改用漸細曲線，腳趾與爪有分界。獅鷲改為鷹喙輪廓。
- 鳥與有翼獸：增加羽軸、羽枝與覆羽，保留翅膀活動群組。
- 龍型怪：增加臉頰鱗片、頸鱗、前肢護鱗、鼻翼、齦線及翼膜分枝紋理。
- 其他種類：龜甲溝縫、蠍鉗與尾節、樹皮與分枝、菌傘紋路與葉脈、眼魔虹膜細絲、史萊姆內部微粒都有各自更新。
- 裝備：胸板、腹部疊片、曲面飾邊、護肩、護脛、鞋尖與背面雕飾。金屬線條使用圓截面，寶石採玻璃材質和細小高光。
- 七套有各自徽記與頭飾：羽翼、藤葉、火焰、雪花、雷電、蝕月與聖環。兩件初始裝備也更新。

模型已烘焙到專案內，遊戲內不必開啟動態 Mesh API。仍以原生幾何與材質呈現；手繪貼圖及插畫中的所有微小紋理尚未完全還原。

## 遊玩

F 騎龍／靠地面下龍；WASD 平飛、空白鍵上升、Q 下降、Shift 加速；E 攻擊、R 互動、B 背包、M 地圖。

沿用 v8 的 126 個分散生成點、巡邏與追擊限制。最高 Lv.800、裝備能力、商店價格、怪物等級和掉落權重保留。購買、持有驗證、傷害、獎勵及飛行位置仍由伺服器判定。

src 為完整客戶端、伺服器與 ModuleScript。安裝 Rojo 後，執行 `python3 tools/build_place.py` 可直接重建已烘焙專案。

`tools/refine_models.py` 為本次可重複執行的造型製作程式，每次從 art/base-v8-recipes.json 重新產生全部配方；`tools/BakeModels.luau` 為 Studio 內烘焙工具，`tools/render_catalog.py` 為 Blender 預覽工具。僅修改配方不會自動取代既有烘焙外觀；重新烘焙後才會反映到正式遊戲。

圖鑑、背包與商店的詳細外觀預設顯示真正的立體模型，可切換設計圖並用左右按鈕旋轉；切換或關閉會釋放舊的預覽。
