## 驗收證據的範圍

`game/VALIDATION.json` 是交付 v9 時的記錄，不是每次 clone 後自動重跑的結果。規則測試包含大量模型幾何斷言。單客戶端整合測試曾通過飛行、購買、裝備和擊殺獎勵；多人、手機與正式存檔仍待驗證。模型渲染預覽與概念圖皆不能取代實機驗收。
