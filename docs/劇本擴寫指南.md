## 延續目前基準

第一部探索七島，由 Lv.1 成長到 Lv.800，以遠古神龍試煉收束。暗黑滅世龍為後續長線伏筆，目前未加入遊戲怪物清單。先決定新增內容是目前七島支線、第一部結尾過場，或第二部；維持既有角色動機與已知世界規則。

每項新增內容標示「已實作」、「敘事提案」或「待製作」。主稿中的新增對話、過場與敘事旗標目前多為提案；遊戲已存在的委託／祕境互動不等於完整劇情流程已串接。

## 場次模板（可複製）

| 欄位 | 填寫內容 |
|---|---|
| 場次 ID／章節 | 例如 ACT02-SC001；避免重複既有 ID |
| 製作狀態 | 敘事提案／製作中／已實作／已驗收 |
| 島嶼／地標／等級 | 對應既有地標，或明確標示新增區域 |
| 出場角色 | 名稱、身份、當場目標及情緒轉折 |
| 觸發／前置旗標 | 何時開始；回鍋、重播與組隊情況如何處理 |
| 敘事目的 | 玩家在此場學到什麼、角色改變什麼 |
| 事件與演出 | 鏡頭、走位、動作、音效與時間順序 |
| 對話 | 角色：台詞；另註表情、停頓與可跳過行為 |
| 玩家目標 | 可驗證的行動；失敗、離線與重試規則 |
| 獎勵 | 經驗、金幣、物品 ID、是否一次性 |
| 完成／後續旗標 | 寫入什麼、解鎖什麼；由伺服器判定 |
| 製作資產 | 模型、動畫、UI、音樂、特效及負責項目 |
| 驗收條件 | 成功、失敗、重複領獎、斷線後續跑等情境 |

## 交給實作時同步

新增怪物或物品需設定唯一 ID，更新 Catalog、WorldData、Settings、外觀配方、地圖、圖鑑和文件。掉落要有總和與互斥規則；確定性劇情獎勵應與隨機戰利品分開。新增存檔欄位要有遷移、重複領取保護與測試。

先在測試體驗完成一條可從頭跑到尾的流程，再擴充同類內容。新增敘事不應在未決定的情況下提高 Lv.800 上限、改掉既有掉落機率或替換玩家已持有的裝備。
